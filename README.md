# 2C Meridian Hotel — Preview Booking Page

A single-page, mobile-first preview booking page for 2C Meridian Hotel ([2cmeridianhotel.com.ng](https://2cmeridianhotel.com.ng)), at 9 Akintonde Street, off A.I.T. Road, Alagbado, Lagos. This is a plain HTML, CSS, and JavaScript scaffold with no framework or build step.

All hotel-specific content lives in `content.json` and must be filled from the real hotel site.
